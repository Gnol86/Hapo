# Hapo 0.1.0

First release of Home Assistant Presence Orchestrator: a standalone local Haxo integration with a built-in English/French panel.

- Six configurable room profiles, including separate triggering/holding roles and improved Bee in the Box behavior.
- Resident presence and sleep, explicit guests, stable customizable home modes and known counts.
- Metadata-based suggestions requiring explicit selection, visual condition editing and revision-protected drafts.
- Native entities and public actions, timed overrides, explanatory activity and redacted diagnostics.
- Three-valued conditions, bounded degraded-state retention, restart handling and cycle detection.

Requires Home Assistant 2026.10.0 or newer. This is an early release; use the migration guide to compare results before switching existing consumers. Hapo does not automatically rewrite other integrations or identify people from motion sensors.

## Français

Première version autonome de Hapo : six profils de présence, sommeil des résidents, invités explicites, modes personnalisables et panneau anglais/français intégré. Les capteurs sont proposés selon leur fonction et leur pièce, sans activation silencieuse.

Les résultats indéterminés, redémarrages, temporisations et dépendances circulaires sont traités explicitement. Les entités natives et actions publiques remplacent les anciens helpers après migration des consommateurs. Consulte le guide de migration avant la bascule domestique.
