# Hapo 0.2.0

Hapo — **Home Assistant Presence Orchestrator** — now shares Halo's panel layout and styling. Bee in the Box also gains an optional door-opening requirement with a configurable recovery period for late or interrupted detections.

## Interface and documentation

- Open directly on a searchable room list, with presence status and a focused detail view.
- Organize room controls into **Presence**, **Detection**, **Timing**, **Context** and **Settings** tabs. Keep residents and global settings in the main navigation.
- Match Halo's header, spacing, controls and theme integration, including mobile navigation and the native Home Assistant menu.
- Preserve configuration drafts across navigation and live updates, validate incomplete fields, and retain conflict protection and access permissions.
- Keep decision evidence tied to the saved configuration while sources are edited in a draft.
- Refresh the English and French README files with six screenshots from a local preview using fictional data. The preview makes no Home Assistant connection.

## Bee in the Box: opening and recovery

- Optionally require a monitored door opening before motion can establish new presence in a clear, closed room. This helps reject wind-triggered garden motion when no access has opened.
- After the last door closes, allow the normal stabilization period followed by a **120-second recovery period by default, configurable per room** in **Timing**.
- Accept late detections and fresh confirmation attempts during that fixed period. An uninterrupted confirmation started before expiry may finish afterward; failed attempts do not extend the deadline.
- Retain confirmed presence during stillness. After the recovery opportunity expires, require another opening before accepting new presence.
- Expose the waiting/recovery reason in the panel, entity attributes and native activity, and the recovery deadline in the panel and entity attributes. Restarts or lost door continuity invalidate the entry opportunity.

**Compatibility:** existing rooms keep their current behavior because the opening requirement is disabled by default. Enable it explicitly for each Bee room that needs it. No configuration migration is required; entity identifiers stay unchanged. Home Assistant 2026.10.0 or newer is still required.

Local validation: **101 Python tests and 20 panel tests**, Ruff, TypeScript and the compiled panel. The release workflow also checks bundle reproducibility, HACS and Hassfest before publication.

## Français

Hapo — **Home Assistant Presence Orchestrator** — reprend la présentation de Halo : liste des pièces avec recherche, état de présence, vue détaillée et onglets **Présence**, **Détection**, **Délais**, **Contexte** et **Réglages**. Les résidents et les réglages globaux restent accessibles dans la navigation principale. Le thème, les contrôles et la navigation mobile sont harmonisés ; les brouillons, la validation, les droits d'accès et la protection contre les conflits sont conservés. Les sources expliquant la présence active restent celles de la configuration enregistrée.

Le profil Bee in the Box propose désormais **Exiger une ouverture avant une nouvelle présence**. Quand cette option est active, les mouvements ne peuvent pas établir une nouvelle présence dans une pièce vide et fermée tant qu'une porte surveillée ne s'est pas ouverte. Après la fermeture du dernier passage, la stabilisation habituelle est suivie d'un **délai de rattrapage de 120 secondes par défaut, configurable par pièce** dans **Délais**.

Ce délai permet une détection tardive ou une nouvelle tentative après une confirmation interrompue. Il reste fixe : les tentatives échouées ne le prolongent pas. Une confirmation continue commencée avant son expiration peut se terminer ensuite. Une fois la présence confirmée, elle reste mémorisée pendant l'immobilité. Après expiration du rattrapage, une nouvelle ouverture est nécessaire. Un redémarrage ou une perte de continuité des capteurs de porte invalide l'autorisation temporaire.

L'option est **désactivée par défaut**, y compris pour les pièces existantes : active-la uniquement dans les pièces Bee concernées. Aucune migration de configuration n'est nécessaire et les identifiants des entités sont conservés. La version minimale reste Home Assistant 2026.10.0.

Les README anglais et français sont renouvelés avec six captures issues d'un aperçu local contenant des données fictives. Validation locale : **101 tests Python et 20 tests d'interface**, Ruff, TypeScript et compilation du panneau ; le workflow vérifie aussi sa reproductibilité, HACS et Hassfest avant publication.
